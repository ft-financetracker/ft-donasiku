# KIA v0.5.6 — Donor Social & Compact Donation Feed

- Live Donation landing dikunci menjadi tepat 3 baris: nominal+badge, program, nama+pesan.
- Feed donasi program desktop: No | Profil | Nama+Pesan | Program | Badge | Nominal+DateTime.
- Layout adaptif: 1 row desktop, 2 row tablet, maksimal 3 row mobile.
- Klik baris donasi membuka timeline dukungan.
- User login dapat Love dan mengirim doa/pesan.
- Profil donor publik menampilkan data aman saja: nama tampilan, verifikasi, level aktivitas, badge, frame, tanpa email/telepon/user_id.
- Badge/level tetap berbasis aktivitas, bukan nominal donasi.
