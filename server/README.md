# KIA Backend v0.5.1

Runtime: Node.js / Render.  
Root Directory di Render: `server`.  
Build: `npm install`.  
Start: `node server.js`.

v0.5.1 menambah:
- fast public cache + warm cache;
- DOKU Checkout Sandbox server-side;
- webhook verification + idempotency;
- Donor Impact API.

Source backend tetap disimpan di GitHub. Commit folder `server/` ke repository lalu biarkan Render auto-deploy. Jangan menaruh credential DOKU di frontend atau file repository.
